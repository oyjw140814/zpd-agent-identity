## 体验

直接打开 `index.html`，或运行 `python3 -m http.server 8080`。

19 道情境题、解密过渡、身份分析、信任度与风险反馈、重新挑战以及声音开关。配有应用图标。

这是个人学习与娱乐互动作品，不是专业测评或官方产品。ZPD、动物城及相关角色名称和形象属于各自权利人。
